数据访问层

本文件夹包含MyBatis Plus Mapper接口，用于数据库操作。

文件说明：
- UserMapper.java             - 用户Mapper
- HealthRecordMapper.java     - 健康记录Mapper
- MedicalHistoryMapper.java   - 病史Mapper
- MedicationRecordMapper.java - 用药记录Mapper
- MedicationReminderMapper.java - 用药提醒Mapper
- SosRecordMapper.java        - SOS记录Mapper
- EmergencyContactMapper.java - 紧急联系人Mapper
