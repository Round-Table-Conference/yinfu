业务逻辑层

本文件夹包含服务层实现类，处理核心业务逻辑。

文件说明：
- AuthService.java             - 认证服务（登录注册、Token生成）
- UserService.java             - 用户服务（资料管理）
- HealthService.java           - 健康服务（健康档案、病史）
- MedicationService.java       - 用药服务（提醒管理）
- SosService.java              - SOS服务（触发记录）
- EmergencyContactService.java - 紧急联系人服务
- AiService.java               - AI服务（聊天、问诊，集成SiliconFlow API）
