数据传输对象

本文件夹包含API请求和响应使用的数据传输对象。

文件说明：
- LoginRequest.java             - 登录请求
- RegisterRequest.java         - 注册请求
- PasswordRequest.java         - 修改密码请求
- UserProfileRequest.java      - 用户资料更新请求
- HealthRecordRequest.java      - 健康记录请求
- MedicalHistoryRequest.java    - 病史请求
- MedicationReminderRequest.java - 用药提醒请求
- SosTriggerRequest.java        - SOS触发请求
- EmergencyContactRequest.java  - 紧急联系人请求
- AiChatRequest.java            - AI聊天请求
- AiDiagnosisRequest.java       - AI问诊请求
