控制器层

本文件夹包含所有REST API控制器，处理HTTP请求。

文件说明：
- AuthController.java           - 认证控制器（登录、注册）
- UserController.java           - 用户控制器（个人信息管理）
- HealthController.java         - 健康控制器（健康记录、病史）
- MedicationController.java     - 用药控制器（用药提醒管理）
- SosController.java            - SOS控制器（紧急求救触发）
- EmergencyContactController.java - 紧急联系人控制器
- AiController.java             - AI控制器（聊天、问诊）
