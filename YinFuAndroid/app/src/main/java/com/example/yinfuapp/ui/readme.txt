UI层源代码

本文件夹包含Android应用的所有界面代码，采用Fragment-based架构。

主要文件说明：
- LoginActivity.kt      - 用户登录界面
- RegisterActivity.kt   - 用户注册界面
- MainActivity.kt       - 主界面（底部导航）

Fragment说明：
- HomeFragment.kt       - 首页（功能入口）
- AiChatFragment.kt     - AI聊天界面
- AiDiagnosisFragment.kt - AI问诊界面
- ClassroomFragment.kt  - 数字课堂
- HealthFragment.kt     - 健康管理
- MedicationReminderFragment.kt - 用药提醒
- PaymentFragment.kt    - 支付帮助
- ProfileFragment.kt    - 个人中心
- PsychologyFragment.kt - 心理测试
- SosFragment.kt        - SOS紧急求救
- TravelFragment.kt     - 出行服务
- LifeServiceFragment.kt - 生活服务
- SocialMediaFragment.kt - 社交媒体
- PhoneBasicFragment.kt - 手机基础教程
- VideoPlayerFragment.kt - 视频播放器
- HealthRecordsFragment.kt - 健康档案
